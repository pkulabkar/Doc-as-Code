# Hardware Configuration Guide
The document spells out the hardware configuration of the software.
System Components

## Hardware Components
- Solvent Delivery System (Pump) – Moves mobile phase
- Autosampler – Injects samples automatically
- Column Compartment – Maintains temperature for separation
- Mass Spectrometer (Triple Quadrupole) – Detects compounds
- Detector – Records signals

The hardware is the prerequisite for the software. The software includes:

| Item | Element |
|------|-----|
| 1 | Software Interface  |
| 2 | Dashboard for monitoring runs  |
| 3 | Method editor |
| 4 | Sample queue manager|
| 5 | Data analysis and reporting module |
