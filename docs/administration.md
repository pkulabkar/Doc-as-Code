# Administration Guide   
The section talks about the user access.
## User & Access Management
Lab Assistants typically have limited permissions, but they should understand:
- Login/Logout
- Use assigned credentials
- Do not share login IDs
- Role-based access

The Lab Assistant role allows:
- Running samples
- Viewing reports
- Basic data entry

The are restricted from:
- System configuration
- Method creation (in most setups)

*Note*: If access issues occur, contact the System Administrator.

## Instrument Readiness Check for lab assistants.
Before starting work, ensure the system is:
- Powered ON
- Connected to software
